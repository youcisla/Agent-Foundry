# Agent Foundry — agent instructions

Canonical instructions for agents working in this repository. Harness-specific
files (`.codex/AGENTS.md`, `.gemini/AGENTS.md`, `.cursor/rules/`) are thin
adapters and must not diverge from this file.

## What this repo is

A Python package + FastAPI daemon, a stdio MCP server, 35 agent skills, 3
agents, and a static web catalog. MIT-licensed, original work.

## Commands

```bash
pip install -e .                     # editable install
python -m pytest tests -q            # unit tests
python scripts/foundry-eval.py       # skill quality gate
bash scripts/validate.sh             # frontmatter lint
bash scripts/nox.sh                  # provenance gate
node scripts/install.js --list       # harness targets
node scripts/install.js --harness=codex --dry-run
```

## Rules

1. **Skills are installed as direct children.** Harnesses scan
   `<root>/<skill>/SKILL.md`. Never install a grouped parent folder.
   See `docs/harness-compatibility.md`.
2. **Privacy.** `docs/research/` and `plans/` are private, gitignored, and
   excluded from the generated site. Never embed their content in `web/`,
   package manifests, or published artifacts.
3. **Skill contract.** Every skill needs YAML frontmatter with `name` and
   `description`; name is lowercase alphanumeric with single hyphens and
   matches its folder. Keep `SKILL.md` under 500 lines and move detail to
   `references/`.
4. **One version source.** `package.json` is canonical. Run
   `python scripts/sync-version.py` after a bump; do not hand-edit version
   strings elsewhere.
5. **Generated web data is disposable.** `web/file-content.js`,
   `web/file-tree.js`, `web/data.json`, and graph files are generated by
   `scripts/gen-site-data.py`. Fix the generator, not the output.
6. **Original work only.** Do not add external project names, copied prose, or
   unlicensed assets. `scripts/nox.sh` enforces this.
7. **Small diffs.** Follow `skills/core/plan-before-code` and
   `skills/core/verify-first`: plan, change only what the request needs, then
   run the gates before claiming completion.
8. **Global config is user-owned.** Adapters copy instructions only when the
   target is missing, and never overwrite `config.toml`, `opencode.json`, or
   user rules.
